# Política de Segurança — Avalia Quiz

Levamos a segurança do **Avalia Quiz** muito a sério. Agradecemos antecipadamente pelos relatórios de segurança responsáveis e pelo apoio da comunidade no fortalecimento do projeto.

---

## 🛡️ Versões Suportadas

Apenas a versão mais recente da branch principal é ativamente suportada com patches de segurança:

| Versão | Suportada |
| :--- | :---: |
| Última Release Main (v1.4.x+) | 🟢 Sim |
| Versões Anteriores / Legadas | 🔴 Não |

---

## 🔒 Reportando uma Vulnerabilidade

**POR FAVOR, NÃO ABRA ISSUES PÚBLICAS NO GITHUB PARA REPORTAR VULNERABILIDADES DE SEGURANÇA.**

Se você descobrir uma falha de segurança (vazamento de credencial, injeção de dados, bypass de autenticação, etc.), informe-nos de forma privada:

1. **Contato Direto**: Envie um e-mail com os detalhes para o mantenedor do repositório ou utilize o recurso **Private Vulnerability Reporting** na aba *Security* do repositório GitHub.
2. **Conteúdo do Relatório**:
   - Descrição detalhada do problema e potencial impacto.
   - Passo a passo legível ou prova de conceito (PoC) para reprodução.
   - Informações sobre versões/ambientes afetados.

---

## ⏱️ Prazo de Resposta

- **Confirmação**: Responderemos em até **48 horas** confirmando o recebimento do relatório.
- **Resolução**: Trabalharemos em uma correção prioritária e notificaremos você assim que o patch for aplicado na release oficial.
